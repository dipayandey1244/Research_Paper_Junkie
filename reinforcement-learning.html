Exploration and exploitation

Exploit by choosing the action with the best current estimate. Explore by choosing an action that could improve future decisions. If one recommendation has 6 clicks in 10 impressions and another has 1 in 1, the second has the higher observed rate and much less evidence.

Multi-armed bandit

Each pull yields an immediate reward. With stationary arms, today’s choice changes what the agent knows while leaving the underlying reward probabilities fixed.

Sequential decision problem

In a Markov decision process, an action can change the next state and the rewards available later. A policy selects actions to maximize expected discounted return.

Three ways to explore. Inject random actions (ε-greedy), favor uncertain estimates through an optimism bonus (UCB), or sample a plausible reward model from a posterior (Thompson Sampling). For an episodic task, a decaying ε schedule can shift the behavior toward exploitation as training progresses.

Multi-armed bandits

Let Nt(a) be the number of times arm a has been pulled before round t, and μ̂t(a) its sample mean. Only the chosen arm’s reward is observed.

ε-greedy

With probability ε, sample uniformly from all K arms. Otherwise, choose the largest sample mean. The greedy arm still has probability ε/K of being selected during exploration. Fixed ε keeps exploring throughout the run, including after a clear leader emerges.

Upper Confidence Bound

Score(a) = μ̂t(a) + c √[ln(t) / Nt(a)]

Pull every arm once before scoring. The bonus grows as an arm goes untested relative to the total number of rounds and shrinks as observations accumulate. Larger c prioritizes uncertainty.

Thompson Sampling

pa | data ∼ Beta(1 + successesa, 1 + failuresa)

For binary rewards, start each arm with a Beta(1, 1) prior. On each round, sample one probability from each posterior and pull the arm with the largest draw. Three successes and one failure give Beta(4, 2), with posterior mean 4/6. The action uses a draw from that distribution.

Q-learning

Q(s,a) estimates the expected discounted return from taking a in state s and then acting optimally. Tabular Q-learning updates the value of the sampled state–action pair using the observed reward r and next state s′.

y = r + γ maxb Q(s′, b) for a continuing transition, and y = r at a terminal state.
Q(s,a) ← Q(s,a) + α [y − Q(s,a)]

Example: with Q(s,a)=0.20, r=0, γ=0.95, a best next-state value of 0.80, and α=0.35, the target is 0.76 and the new value is 0.396. The update is off-policy: the behavior can explore with ε-greedy while the target uses the greedy next action.

Deep Q-Networks

When a Q-table becomes too large, a network Qθ(s,·) can represent action values with shared weights. In this demo it maps a one-hot state through two ReLU layers to four action values.

  1. Use ε-greedy with the online network and store (s, a, r, s′, done) in replay memory.
  2. Sample a minibatch from replay. Replay mixes experience from different points in training.
  3. For continuing transitions, compute y = r + γ maxb Qθ⁻(s′, b) using the frozen target network. At a terminal transition, use y = r.
  4. Minimize Huber loss between Qθ(s,a) and y. Periodically copy the online weights to the target network.

The max can overestimate action values when predictions are noisy. Double DQN addresses that by choosing the next action with the online network and evaluating it with the target network. This lab uses the standard DQN target.

Practice and references

  • Set ε to zero and rerun the bandit lab across three seeds. Compare selection counts to see when greedy commits to a weaker arm.
  • Reset Q-learning. Step through an update into a trap and verify why the target is exactly −1.
  • Train DQN in 100-episode blocks. Record the greedy route alongside the latest loss. Use the training settings in the guide to explain what changes between blocks.

Read Sutton and Barto, Chapters 2 and 6, Russo et al. on Thompson Sampling, Watkins and Dayan on Q-learning, and Mnih et al. on DQN.
